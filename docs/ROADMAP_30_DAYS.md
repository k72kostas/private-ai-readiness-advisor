# 30-day roadmap

## Days 1-3: Foundation
- Publish repository, license, issue templates, and project board.
- Run the starter locally and capture the first screenshot.
- Replace generic wording with your own project story.

## Days 4-7: Evidence
- Review every scoring rule and document its rationale.
- Add three public, synthetic scenarios: small pilot, regulated enterprise, high-concurrency service.
- Add unit tests for boundaries and invalid inputs.

## Days 8-12: NVIDIA integration
- Connect one openly licensed model through an NVIDIA NIM-compatible endpoint.
- Record model name, license, runtime, hardware, latency, and configuration.
- Keep the deterministic path available for reviewers without credentials.

## Days 13-16: Differentiation
- Add a comparison view for two scenarios.
- Add a downloadable Markdown report.
- Add a simple benchmark-import format for measured latency, throughput, and GPU utilization.

## Days 17-20: Responsible AI
- Add threat model, privacy note, model-card link, and prompt-injection test cases.
- Add clear “assumption”, “measured”, and “recommended next test” labels.
- Verify that no company-confidential material is present.

## Days 21-23: Documentation
- Improve README with screenshots, architecture, quick start, limitations, and reproducibility steps.
- Add CONTRIBUTING.md, SECURITY.md, and a release checklist.
- Ask two technical peers to reproduce the setup from the README.

## Days 24-26: Presentation
- Record a clean 90-second demo.
- Create one architecture image and one result screenshot.
- Draft the social post with project link, tagged judge, and #NVIDIAGTC.

## Days 27-28: Quality gate
- Run tests from a clean environment.
- Check links, license notices, secrets, accessibility, and mobile layout.
- Tag v0.1.0 and attach reproducible sample output.

## Days 29-30: Submission
- Re-read the official contest page and the terms for the judge/path you selected.
- Publish the video or project link using the required tags and hashtag.
- Save evidence of the published entry and final commit.
