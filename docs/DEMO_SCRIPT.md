# 90-second demo script

**0-10 seconds, problem**
“Enterprise teams want private AI, but early sizing discussions often hide assumptions. I built the Private AI Readiness Advisor to make those assumptions visible.”

**10-25 seconds, form**
“An architect enters the deployment boundary, data sensitivity, concurrency, availability target, and candidate open-model size.”

**25-50 seconds, result**
“The transparent rules engine returns a readiness score, an approximate VRAM planning estimate, risks, a reference architecture, and concrete next steps. Every output includes a clear benchmarking disclaimer.”

**50-68 seconds, NVIDIA use**
“The assessment runs without an LLM. Optionally, an open model served through an NVIDIA NIM-compatible endpoint converts the structured result into an executive summary. The model never changes the deterministic score.”

**68-82 seconds, openness**
“The code, calculation, test, architecture diagram, limitations, and sample input are open source and reproducible.”

**82-90 seconds, close**
“My goal is to help infrastructure teams move from AI enthusiasm to a safe, measurable pilot. I’m Konstantinos Kaminaris, and this is my #NVIDIAGTC project.”
